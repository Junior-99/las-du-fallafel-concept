# L As du Fallafel independent concept

Seven-page React/Vite creator concept, not an official or commissioned restaurant website. No orders, queue tickets or reservations are accepted.

Run `npm ci`, `npm run dev`, `npm run build`. Deploy `dist` using relative assets to free GitHub Pages.

Features: English/French public content toggle persisted between pages; food guide, 60 genuine public post previews with source links, three-page photo wall, up to twelve saved references, validated visit planner, local search/status/notes/export workspace, optional consent-based creator inbox and protected authenticated dashboard. Original Three.js illustrative pita scroll/drag scene, reduced-motion handling and responsive navigation.

Sources: https://www.instagram.com/lasdufallafel/ and https://parisjetaime.com/eng/restaurant/l-as-du-fallafel-p455 . Verified profile describes since 1979, 34 rue des Rosiers, closure Friday night/Saturday. Confirm daily hours and exceptions directly. Older asdufallafel.com returned 404; hosted references were inaccessible. This does not prove the business never had a website.

Media: all 60 images collected in a bounded research session are included; this is not all 161 posts or every carousel slide. Reel covers are stills. Public guest photos do not endorse this site. Facade reference comes from Paris tourism. Per-image original links retained. Rights remain with creators; business/media permission required for official use. No generated photography, paid templates or paid services used.

Shared inbox uses previously tested Supabase membership/RLS policies. Creator must register and verify their own approved email. No passwords, service-role keys or real restaurant integrations included. Current menu, prices, ingredient/allergen information and operational connections require business handover.
